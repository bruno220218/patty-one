# Patty One — Roadmap

- [ ] Shell: sidebar (desktop) / bottom bar (mobile), light/dark theme, pt-BR
- [ ] Data access layer over localStorage (swappable for a database), unique IDs
- [ ] Checklists: create, edit, duplicate, delete (confirm), tasks add/edit/delete/reorder, task count, empty state
- [ ] Projetos: "Novo projeto" from checklist or empty; name (required), description, optional due date
- [ ] Rule: tasks copied from checklist with new IDs, all unchecked; projects and checklists independent afterwards
- [ ] Project card: status, progress bar, done tasks, due date; edit, duplicate, archive, delete (confirm)
- [ ] Arquivados: list archived projects, restore, delete
- [ ] Project screen: name, description, status, progress % (0% with no tasks), checkbox tasks with completion timestamp, add/edit/delete/reorder tasks, back to projects
- [ ] Tests for the business rules
- [ ] Checklist option "Parâmetros fixos": projects created from it inherit a lock (tasks only checkable; name/description/due date still editable); badge on checklist card; toggling later doesn't affect existing projects
- [ ] App name is "Patty One" (replaces Trilha) everywhere
